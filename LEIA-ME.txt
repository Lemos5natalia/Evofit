EVOFIT V5 — BIOIMPEDÂNCIA E MEDIDAS AMPLIADAS

Atualização do Evofit: importação de imagem de ficha de bioimpedância com OCR (leitura de texto no navegador), campos ampliados para composição corporal e medidas corporais, e conferência antes de salvar.

INSTALAÇÃO:
1. Extraia este ZIP.
2. No repositório GitHub Evofit, Add file > Upload files.
3. Envie os arquivos desta pasta para a raiz do repositório (não envie a pasta nem o ZIP).
4. Commit changes.
5. Após publicação, abra https://lemos5natalia.github.io/Evofit/?v=5

OCR: requer conexão para carregar a biblioteca Tesseract.js do CDN. A imagem é processada localmente no navegador. OCR pode cometer erros: revise os campos e compare com o original antes de salvar. Nesta versão, importação de imagem JPG/PNG; PDF não suportado.

Dados: registros são armazenados no navegador/dispositivo. Faça backup regularmente. Não use dados sensíveis. GitHub Pages é público e o app não tem autenticação.


V6: leitura OCR mais conservadora. Só preenche automaticamente valores quando rótulo e número estão na mesma linha e deixa ambiguidades em branco. Sempre revisar.
